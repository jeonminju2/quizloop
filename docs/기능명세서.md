# 기능명세서

## 1. 프로젝트 개요

**한 줄 정의**: 강의자료를 업로드하면 AI가 문제를 생성하고, 학생의 풀이를 채점·분석해서 취약 개념 위주로 다시 문제를 내주는 시험공부용 학습 도구.

**타겟 사용자**: 시험/과제를 앞둔 대학생 (전공 상관없이 텍스트 기반 강의자료가 있는 과목이면 적용 가능)

**차별점**: 기존 "자료 업로드 → 문제 생성기" 류(예: 큐레카)는 생성까지만 하고 끝난다. 이 프로젝트는 **학생이 실제로 풀고, 어디서 왜 틀렸는지 분석하고, 그 약점만 골라 다시 출제하는 순환 구조**까지 만든다. 즉 "문제 생성기"가 아니라 "약점 교정 루프"가 제품의 본질.

## 2. 핵심 사용자 시나리오

1. 학생이 강의자료(PDF/PPT/텍스트)를 업로드한다.
2. 시스템이 자료를 요약하고 핵심 개념 단위로 분해한다.
3. 학생이 문제 생성을 요청한다 (범위·난이도·유형 선택).
4. 시스템이 자료에 근거한(grounded) 문제를 생성한다.
5. 학생이 문제를 푼다.
6. 시스템이 채점하고, 틀린 문제를 유형별로 분석한다 (단순 실수 / 개념 혼동 / 미학습).
7. 취약 개념을 시각적으로 보여준다.
8. 취약 개념 위주로 재출제를 제안한다 → 5번으로 순환.
9. (선택) 여러 회차의 결과를 누적해 학습 곡선을 보여준다.

## 3. 기능 목록

### 3.1 MVP (1차 구현 범위)

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 자료 업로드 | PDF/PPT/TXT 업로드, 텍스트 추출 | P0 |
| 자료 청크·요약 | 페이지/슬라이드 단위로 분할 후 핵심 개념 요약 | P0 |
| 문제 생성 | 객관식(4지선다) + 단답형 생성, 문항 수/난이도 선택 | P0 |
| 자료 근거 표시 | 각 문제가 어느 자료(페이지)에서 나왔는지 출처 표기 | P0 |
| 풀이 제출·채점 | 객관식 자동 채점, 단답형은 키워드/유사도 기반 채점 | P0 |
| 오답 유형 분류 | 오답을 "단순 실수/개념 혼동/미학습"으로 자동 태깅 | P0 |
| 취약 개념 집계 | 오답 태그를 개념 단위로 집계해 취약 개념 목록 산출 | P0 |
| 재출제 | 취약 개념만 골라 새 문제 세트 생성 | P0 |

### 3.2 확장 기능 (여유 있으면)

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 학습 곡선 대시보드 | 회차별 정답률·취약개념 변화 추이 시각화 | P1 |
| 유사개념 혼동 매핑 | "A개념을 B개념으로 착각" 패턴을 그래프로 표시 | P1 |
| 난이도 자동 조정 | 정답률에 따라 다음 문제 난이도 자동 상향/하향 | P1 |

| 협업 모드 | 스터디원과 같은 문제 세트 풀고 결과 비교 | P2 |

## 4. 핵심 플로우 (구조화 출력 기준)

```
[업로드] → [텍스트 추출/청크] → [임베딩 저장]
     → [문제 생성 요청 (범위/난이도/유형)]
     → [LLM: RAG 검색 → 구조화 문제 JSON 생성]
     → [학생 풀이 제출]
     → [채점 (객관식: 정답비교 / 단답: LLM 채점+근거자료 대조)]
     → [오답 태깅 (LLM 분류: 실수/개념혼동/미학습 + 관련 개념 태그)]
     → [취약개념 집계 (개념별 오답률 랭킹)]
     → [재출제 (취약개념 가중치 반영해 문제 재생성)]
```

## 5. 비기능 요구사항

- **정확성**: 문제가 업로드 자료 범위를 벗어나지 않도록 RAG grounding 필수 (환각 방지)
- **일관성**: 문제 생성 출력은 고정된 JSON 스키마로 강제 (프론트에서 파싱 안정성 확보)
- **응답 속도**: 문제 10문항 생성 기준 10초 내외 목표 (스트리밍 응답 고려)
- **데이터 프라이버시**: 업로드 자료는 사용자 본인만 조회 가능하도록 격리

## 6. MVP 제외 범위 (명시적으로 안 함)

- 실시간 협업, 모바일 앱, 다국어 지원은 1차 범위에서 제외
- 손글씨/이미지 문제(도표 인식 등)는 제외, 텍스트 기반 자료만 우선 지원
